## Kỹ thuật

- Monorepo `apps/web` (Next.js 16) + `apps/api` (NestJS 11) + PostgreSQL 16, Prisma 7 migration + seed.
- `docker-compose.yml` chạy web + API + database ở local; `GET /health` kiểm tra kết nối DB.
- CI: lint, unit test (API + web), integration test API trên PostgreSQL thật, E2E Playwright menu → xác nhận đơn, build.
- CD: image Docker tag theo commit SHA / semver đẩy lên GHCR, migration an toàn, deploy Render bằng secret, smoke test, rollback tự động.

## Sửa lỗi đáng chú ý

- Bọc `useParams` trong `Suspense` cho `/orders/[id]` (build lỗi với `cacheComponents`).
- Dockerfile dùng `node_modules` được hoist từ npm workspaces.
- Siết CORS về danh sách domain (`CORS_ORIGIN`) thay vì cho mọi nguồn.

## Lưu ý khi nâng cấp

- Chạy `npx prisma migrate deploy` trước khi khởi động API (pipeline CD đã tự làm).
- Production cần `CORS_ORIGIN` chứa domain web, hoặc web dùng proxy `API_PROXY_TARGET` (xem `docs/deployment.md`).
